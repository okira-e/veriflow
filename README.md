# Veriflow

Veriflow is a CLI tool for testing APIs through flows of requests.
It makes it easy to describe and run end-to-end API scenarios (like onboarding a user) using a single JSON configuration file (veriflow.json).

Forget about writing full integration tests in a framework — Veriflow lets you validate endpoints, chain outputs (like tokens or IDs) across requests, and run everything from the command line.
